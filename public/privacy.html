Privacy and data handling

Updated September 5, 2026. The static TenantBoundary site keeps its worksheet and report viewer local. Booking the $349 offer happens on Upwork.

Current website behavior: TenantBoundary has no analytics, customer account, hosted form submission, or direct payment processor. The scope worksheet and report viewer run in your browser.

Information processed locally

If you use the scope worksheet, application details and contact fields remain in the browser unless you copy or download the generated text. If you open a report file, JavaScript reads it in memory for display; this site does not upload it.

Upwork is a separate service

The approved $349 Upwork Project Catalog offer is the current booking and marketplace message path. Following that link leaves this website. Upwork processes account, message, order, and payment information under its privacy notice.

Information not requested publicly

Do not enter API keys, database passwords, service-role credentials, database exports, customer records, or other secrets into this website or the initial Upwork requirements. A least-privilege access process is agreed only after a contract and written scope exist.

Engagement data

For an approved engagement, access, evidence retention, deletion, and any subprocessors are documented in the written scope. The default is staging, synthetic data, least privilege, time-bounded access, and redacted reporting.

Direct contact remains closed

The Upwork project is the current platform contact path. Direct website intake remains disabled until a verified public operator contact, deletion route, and applicable operating details are released.
