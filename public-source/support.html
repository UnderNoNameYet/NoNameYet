QUICK DIAGNOSTICS

Three checks before
you reset anything.

  1. 01

    Confirm the browser profile

    Local cases are tied to the same browser and profile used when they were created. A private window, another browser, or another device will not share that storage.

    DO NOT CLEAR SITE DATA YET
  2. 02

    Export before experimenting

    If the case still opens, download a JSON backup first. For PDF problems, use the browser print dialog and select Save as PDF.

    MAKE A RECOVERABLE COPY
  3. 03

    Reload once while online

    The web app uses a service worker. A successful online reload can obtain the newest release before you test offline again.

    THEN TEST OFFLINE

FREQUENT QUESTIONS

Short answers,
clear boundaries.

Does RebuttalKit submit the dispute for me?+

No. You verify the packet and submit it through the processor’s current portal. RebuttalKit never asks for processor credentials.

Can support recover a deleted case?+

No. The beta does not have a case-data server. If local browser data is deleted and no JSON export exists, RebuttalKit cannot recover the case.

Why does the readiness score change?+

It reflects organization inside the tool: required fields, evidence statuses, timeline coverage, and final checks. It is not a probability or legal assessment.

Can I send evidence through the feedback form?+

No. Feedback opens a public GitHub issue. Never include private customer, transaction, credential, or evidence data.

Is premium support active?+

No. Payment and premium service are disabled. The premium page describes criteria for a future product, not a service available today.
