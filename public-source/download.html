NATIVE INSTALLER ROADMAP

Different platforms need
different delivery choices.

Detecting your platform…

WINDOWS / PLANNEDSigned installer + portable choice

The standard installer should handle shortcuts and updates. A portable package would serve locked-down or no-install workflows.

Target: Windows 10/11 · x64PAYMENT AND DOWNLOAD DISABLED
MACOS / PLANNEDArchitecture-specific disk images

Apple silicon and Intel machines need clearly labeled builds so users do not have to guess which binary fits.

Target: current supported macOS releasesSIGNING / NOTARIZATION REQUIRED
LINUX / PLANNEDPortable + distribution package

An AppImage can travel between distributions, while a Debian package fits users who want system integration.

Target: x86_64 desktop LinuxPACKAGE TESTING REQUIRED
