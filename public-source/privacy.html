Privacy details · beta version

Your case stays in your browser.

RebuttalKit is delivered as a static website. It does not operate an application server that receives the case details you type into the builder.

Plain-language summary

  • No RebuttalKit account
  • No processor password or account connection
  • No analytics tracker in the product
  • No case-data upload endpoint
  • Local export and deletion controls

What is stored

The builder can store transaction fields, evidence statuses, evidence notes, and timeline events in local browser storage on the device you use. This makes the case available when you return with the same browser profile.

RebuttalKit does not currently request or store card numbers, processor credentials, government identifiers, or payment information. Do not enter unnecessary sensitive information into notes.

What is transmitted

The application does not send case form values to a RebuttalKit backend because no case-data backend exists. GitHub Pages delivers the static website and may process ordinary technical request information such as IP address, browser details, requested URL, and timestamps under GitHub’s own service practices. That infrastructure information is separate from the case content stored by the browser application.

The beta contains no advertising scripts and no product analytics tracker.

Exports and deletion

You can export the current case as JSON and the generated response as text. Keep exports only in a location you trust. Selecting Reset deletes the current locally stored case from the browser application. Clearing browser site data can also remove the local case, so export a backup first.

Offline cache

After the first successful visit, the installable version can cache the application interface and public guidance pages for offline access. Case entries remain local. Remove the installed app or clear site data to remove its cache.

Security limits

Local-first storage reduces server exposure, but it cannot protect a compromised, shared, or unlocked device. Use a trusted device, keep the operating system updated, and avoid shared browser profiles. RebuttalKit cannot recover a local case after browser data has been deleted.

Paid review is not active

Payment and secure document intake are intentionally disabled during beta. Do not send customer documents, credentials, or card data through social messages or unapproved channels. A separate service privacy notice and secure transfer process must be published before any human review is sold.
